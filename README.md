# ChefCloud — Операционная система кухни ресторана

Профессиональная система управления блюдами, технологическими картами и производством для бренд-шефов, шеф-поваров и рестораторов.

---

## Что умеет ChefCloud

- **🍽️ Меню** — карточки блюд с фото, составом, технологией, стандартом подачи и критическими точками качества
- **🖨️ Печать** — премиальная карточка А4 из браузера (фото, состав, технология, стандарт)
- **🥣 Полуфабрикаты** — база П/Ф с составом и технологией
- **📦 Склад** — справочник товаров
- **🤖 AI** — чат-интерфейс помощника шеф-повара (готов к подключению нейросети)
- **💾 Резервное копирование** — экспорт/импорт всей базы одним JSON-файлом

## Установка (Windows, PowerShell)

### Шаг 1 — Установите Node.js

Скачайте с официального сайта: **https://nodejs.org** (версия LTS, 18+)

Проверьте установку:
```powershell
node --version
npm --version
```

Должно вывести что-то вроде `v20.x.x` и `10.x.x`

---

### Шаг 2 — Распакуйте архив

Разархивируйте скачанный ZIP в любую папку, например:
```
C:\Projects\ChefCloud\
```

---

### Шаг 3 — Откройте папку в PowerShell

```powershell
cd C:\Projects\ChefCloud\TTK-parser-main
```

---

### Шаг 4 — Установите зависимости

```powershell
npm install
```

Подождите 1–2 минуты. Появится папка `node_modules`.

---

### Шаг 5 — Запустите приложение

```powershell
npm run dev
```

Откройте браузер и перейдите по адресу:
```
http://localhost:5173
```

---

### Шаг 6 — Остановка

Нажмите `Ctrl + C` в PowerShell.

## Хранение данных

Сейчас все данные хранятся в `localStorage` браузера на вашем устройстве.

**Важно:**
- Данные привязаны к конкретному браузеру и устройству
- Перед крупными изменениями всегда делайте резервную копию:
  **Настройки → 💾 Резервное копирование → Создать резервную копию**
- Файл `.json` сохраните на компьютер или в облако (Google Drive, Яндекс Диск)

## Структура проекта

```
src/
├── App.jsx                    # Главный файл, роутинг
├── components/
│   ├── BackupSection.jsx      # Резервное копирование
│   ├── icons.jsx              # SVG иконки
│   └── ui.jsx                 # Базовые компоненты (Tag, SEL_ST и др.)
├── hooks/
│   ├── useReferenceTtk.js     # Хранилище блюд (localStorage)
│   ├── useNomenclature.js     # Хранилище номенклатуры
│   ├── useProducts.js         # Хранилище склада
│   ├── useSemifinished.js     # Хранилище П/Ф
│   ├── useTtkCategories.js    # Хранилище категорий
│   └── useBackup.js           # Логика резервного копирования
└── pages/
    ├── AiAssistantPage.jsx    # AI чат-интерфейс
    ├── ReferenceTtk.jsx       # Главная: список и карточка блюда
    ├── Nomenclature.jsx       # Справочник номенклатуры
    ├── ProductsPage.jsx       # Склад (товары)
    ├── SemifinishedPage.jsx   # Полуфабрикаты
    └── Placeholder.jsx        # Заглушки для будущих разделов
```

## Ключи хранения в localStorage

| Данные | Ключ |
|---|---|
| Блюда | `academy_printable_reference_ttk_v1` |
| Номенклатура | `klevo_nomenclature` |
| Товары (склад) | `klevo_products` |
| Полуфабрикаты | `klevo_semifinished` |
| Категории | `klevo_ttk_categories_v1` |

**Эти ключи никогда не меняются** — ваши данные всегда в безопасности.

## Деплой на Railway

1. Создайте аккаунт на **https://railway.app**
2. Создайте новый проект → Deploy from GitHub
3. Или используйте Railway CLI:
```powershell
npm install -g @railway/cli
railway login
railway up
```

Файл `nixpacks.toml` уже настроен для Railway.
