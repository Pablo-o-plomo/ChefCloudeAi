# ChefCloud

## Описание

React + Vite приложение для управления ТТК, производством и базой знаний ресторана.

## Архитектура

- App.jsx — главный компонент.
- pages/ — страницы.
- hooks/ — бизнес-логика.
- components/ — UI.
- lib/ — Supabase.
- services/ — сервисы.
- domain/ — модели.
- public/data/ — статические данные.

## Основные разделы

- Меню
- Эталонные ТТК
- Полуфабрикаты
- Производство
- Печать
- Контроль качества
- AI
- Аналитика

## Хранение данных

- localStorage
- Supabase (fallback)

## Основные хуки

- useReferenceTtk
- useProducts
- useSemifinished
- useNomenclature

## Правила разработки

- рабочая ветка develop;
- сначала анализ;
- потом план;
- потом ожидание подтверждения;
- после изменений npm run build;
- показать git diff;
- не делать git push;
- не делать git commit без разрешения;
- не менять UI без запроса;
- сохранять обратную совместимость.

В дальнейшем при изучении проекта дополняй PROJECT_CONTEXT.md автоматически новой информацией.
